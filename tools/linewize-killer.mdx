The Linewize Killer bookmarklet disables Linewize's content filtering for your current browser session by redirecting you to `http://autologout.linewize.net/` — Linewize's own built-in auto-logout endpoint. Hitting this URL causes the Linewize filtering system to log itself out, lifting restrictions until the session resets.

## How It Works

When you click the bookmarklet, it immediately sets `window.location.href` to `http://autologout.linewize.net/`. This is Linewize's internal auto-logout URL; navigating to it instructs the filter to end its active session, effectively disabling content filtering for the current browser session.

While the redirect executes, the bookmarklet also prints a sequence of log messages to the browser console that document each step of the process:

1. `Finding Sercet INternals...`
2. `Unblocking Ratelimit Method 2`
3. `Decrypting security keys to gain access to the database...`
4. `Fetching user data from the database...`
5. `Initiating database unblocking protocol...`
6. `Analyze Viewing`
7. `Re-routing traffic...`
8. `System unblocked successfully!`

These messages are cosmetic — the redirect to `autologout.linewize.net` is what actually triggers the bypass.

## Usage

<Steps>
  <Step title="Copy the bookmarklet code">
    Copy the full JavaScript code from the code block below.
  </Step>
  <Step title="Add it as a browser bookmark">
    Create a new bookmark in your browser. Set the **name** to anything you like (e.g. `Linewize Killer`) and paste the copied code as the **URL**.
  </Step>
  <Step title="Click the bookmark on a filtered page">
    When you encounter a page blocked by Linewize, click the bookmark in your bookmarks bar. Your browser will be redirected to `autologout.linewize.net`, disabling the filter for the session.
  </Step>
</Steps>
