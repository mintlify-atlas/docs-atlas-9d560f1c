Proxies Menu Lite is the lightweight companion to the full Proxies Menu. It is designed for fast deployment in situations where minimal script overhead is required — stripping the full Proxies Menu down to its essentials so it loads and runs as quickly as possible. Like its full-featured sibling, it provides a floating overlay for launching bookmarklets without navigating away from the current page.

<Note>
  This tool is currently a **placeholder**. The full Proxies Menu Lite code is still being developed. In the meantime, use the full Proxies Menu, which provides identical functionality with a complete draggable UI and pre-loaded bookmarklets.
</Note>

## Use the Full Proxies Menu Instead

Until Proxies Menu Lite is available, the full Proxies Menu is the recommended alternative. It includes the same draggable overlay pattern, the I-Ready bypass, a redirect blocker, and is fully customisable.
