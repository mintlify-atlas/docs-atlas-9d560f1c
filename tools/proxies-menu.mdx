The Proxies Menu bookmarklet injects a draggable floating overlay panel directly into the current web page, giving you instant one-click access to a collection of bookmarklets without navigating away. The menu sits on top of page content, can be repositioned anywhere on screen, and can be hidden at any time with a keyboard shortcut.

## Features

- **Draggable UI** — click and drag the panel to move it anywhere on screen.
- **Keyboard shortcut** — press `Ctrl+E` to instantly hide the menu.
- **Pre-loaded bookmarklets** — ships with three ready-to-use entries (see below).
- **Stays on the current page** — unlike the Linewize Killer, this tool does not redirect your browser.

## Included Bookmarks

The menu is pre-configured with the following three bookmarklet entries:

| Name | What it does |
|---|---|
| **I-Ready** | Fetches `bookmarklet.js` from `https://plu.wiki/files/bookmarklet.js` and evaluates it in the current page context, loading the I-Ready bypass suite without a redirect. |
| **Bookmarklet 2** | Demo entry — displays an `alert` with the message `Hello from bookmarklet 2!`. Replace this with any bookmarklet URL of your choice. |
| **Redirect Block** | Sets `window.onbeforeunload` to return an empty string, causing the browser to prompt for confirmation before navigating away — useful for preventing accidental redirects. |

## Usage

<Steps>
  <Step title="Copy the bookmarklet code">
    Copy the full JavaScript code from the code block below.
  </Step>
  <Step title="Add it as a browser bookmark">
    Create a new bookmark in your browser. Set the **name** to something recognisable (e.g. `Proxies Menu`) and paste the copied code as the **URL**.
  </Step>
  <Step title="Click the bookmark on any page">
    Click the bookmark from your bookmarks bar on any page. A floating dark panel labelled **Bookmarklets** will appear in the top-right corner of the page.
  </Step>
  <Step title="Drag the menu where you need it">
    Click and hold the panel to drag it to a convenient position on screen.
  </Step>
  <Step title="Use a bookmarklet or hide the menu">
    Click any entry in the list to run it. Press `Ctrl+E` to hide the panel when you are done.
  </Step>
</Steps>

## Bookmarklet Code

```javascript
javascript:(function() {  var bookmarks = [    {      name: "I-Ready",      url: "javascript:fetch('https://plu.wiki/files/bookmarklet.js').then(r => r.text()).then(r => eval(r))"    },    {      name: "Bookmarklet 2",      url: "javascript:alert('Hello from bookmarklet 2!');"    },    {      name: "Redirect Block",      url: "javascript:(function(){window.onbeforeunload=function(){return '';}})();');"    }  ];  var menu = document.createElement("div");  menu.style.position = "fixed";  menu.style.top = "10px";  menu.style.right = "10px";  menu.style.width = "150px";  menu.style.height = "250px";  menu.style.background = "rgba(0,0,0,0.8)";  menu.style.borderRadius = "10px";  menu.style.zIndex = "9999";  menu.style.cursor = "move";  menu.style.userSelect = "none";  menu.style.opacity = "0.8";  menu.style.transition = "opacity 0.3s ease-in-out";  var header = document.createElement("div");  header.style.padding = "10px";  header.style.color = "white";  header.style.fontSize = "18px";  header.style.fontWeight = "bold";  header.style.textAlign = "center";  header.innerHTML = "Bookmarklets";  var content = document.createElement("div");  content.style.padding = "10px";  content.style.height = "200px";  content.style.overflowY = "auto";  for (var i = 0; i < bookmarks.length; i++) {    var bookmark = bookmarks[i];    var link = document.createElement("a");    link.href = bookmark.url;    link.style.display = "block";    link.style.marginBottom = "10px";    link.style.color = "white";    link.style.textDecoration = "none";    link.innerHTML = bookmark.name;    content.appendChild(link);  }  menu.appendChild(header);  menu.appendChild(content);  document.body.appendChild(menu);  var isDragging = false;  var startX = 0;  var startY = 0;  var currentX = 0;  var currentY = 0;  function handleMouseDown(e) {    startX = e.clientX;    startY = e.clientY;    currentX = menu.offsetLeft;    currentY = menu.offsetTop;    isDragging = true;  }  function handleMouseUp(e) {    isDragging = false;  }  function handleMouseMove(e) {    if (isDragging) {      var deltaX = e.clientX - startX;      var deltaY = e.clientY - startY;      menu.style.left = currentX + deltaX + "px";      menu.style.top = currentY + deltaY + "px";    }  }  function handleKeyDown(e) {    if (e.ctrlKey && e.keyCode == 69) {      menu.style.display = "none";    }  }  menu.addEventListener("mousedown", handleMouseDown);  document.addEventListener("mouseup", handleMouseUp);  document.addEventListener("mousemove", handleMouseMove);  document.addEventListener("keydown", handleKeyDown);})();
```

<Tip>
  To add your own bookmarklets, edit the `bookmarks` array at the top of the code before saving it as a bookmark. Each entry is an object with a `name` string and a `url` string containing a `javascript:` URI:

  ```javascript
  var bookmarks = [
    {
      name: "My Tool",
      url: "javascript:/* your code here */"
    },
    // add more entries as needed
  ];
  ```

  See the [Bookmarklet Menu](/tools/bookmarklet-menu) page for more detail on customising the array.
</Tip>
