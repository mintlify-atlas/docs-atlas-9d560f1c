Hackwize has an active community of students and developers. Join to get help, share hacks, and access unreleased code that hasn't made it into the main repository yet.

## Discord

Discord is the primary hub for all things Hackwize. It's where the developers share unreleased and experimental code, answer questions, and collaborate on new bypasses. If you want early access to tools that aren't in the public repo yet, this is the place to be.

## GitHub

The Hackwize source code is hosted on GitHub. You can browse the code, report bugs, suggest features, or submit pull requests directly from the repository.

<Card title="Hackwize on GitHub" icon="github" href="https://github.com/sh495/Hackwize">
  Star the repo, open issues, or contribute pull requests. All contributions are released into the public domain under the Unlicense.

## Contributing

Because Hackwize is released under the [Unlicense](/license) — a public domain dedication — anyone can fork it, modify it, and redistribute it freely, with or without attribution, for any purpose. There are no licensing hoops to jump through.

If you've built an improvement or discovered a new bypass technique, submitting it via a GitHub issue or pull request is very welcome. The project grows through community contributions, and since everything is public domain, your work benefits everyone without restriction.

<Tip>
  The Discord server is the best place to get early access to new tools and experimental bypasses before they're released to the public repo.
</Tip>
